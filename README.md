# AURA — Onboarding UI Design

### Discover More. Do More.

AURA is a modern, premium three-step onboarding experience designed to introduce users to an application's core features through elegant typography, interactive transitions and minimalist visual storytelling.

Built as part of the Pynexia Technology UI/UX Design Internship.

---

## Preview

AURA features a sophisticated editorial-inspired interface with a warm ivory background, muted sage-green accents, elegant serif typography and subtle animated particles.

## Features

- **Three-step onboarding:** A structured introduction to the application.
- **Interactive navigation:** Functional Skip, Continue and Get Started buttons.
- **Dynamic pagination:** Navigate between onboarding screens.
- **Animated background:** Continuously moving upward particles.
- **Editorial illustrations:** Custom geometric visual compositions.
- **Smooth transitions:** Subtle animations and micro-interactions.
- **Responsive design:** Adaptable layouts for desktop and mobile.
- **Keyboard navigation:** Navigate using keyboard controls.
